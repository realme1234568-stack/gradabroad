# Free SEO setup — 24 October 2026

## Technical configuration

- Home, catalogue, contact and policy pages have appropriate descriptions, canonical URLs and social metadata. Homepage design remains unchanged; its client interface moved to HomePage.tsx so the page can export server metadata.
- Each published English-taught public program receives program/university-specific metadata and valid Course/Breadcrumb JSON-LD. JSON serialization escapes script-breaking characters. Markup does not promise rich results.
- Browse Programs now renders listings on the server using the existing anonymous public catalogue API. Degree selection and pagination use actual links; GET search forms preserve the degree and reset pagination. Links work without JavaScript. Interactive shortlisting remains available after hydration.
- Unfiltered paginated catalogue pages have individual canonical URLs. Search/filter variants, empty catalogues and temporary error pages are marked noindex. Invalid/out-of-range pages return not found.
- Public reads never use an account session, cookie, or service-role key. Public query results are cached for five minutes to reduce database usage.
- `/sitemap.xml` lists 214 public URLs: 200 validated program pages, 10 catalogue pages and four static pages. XML query separators are escaped. No private account data or fabricated modification dates are included. The route regenerates through Next caching; public-data fetch lifetime currently results in a five-minute revalidation interval. A database failure throws instead of returning a successful empty sitemap.
- `/robots.txt` points to the sitemap and allows public crawling. Account/auth/admin pages carry noindex metadata and response headers. API routes are excluded from crawling. Authentication and existing row security remain the actual privacy protections; robots rules are not access control.
- Preview deployments receive noindex rules and discourage crawling.

## Google setup and free operation

Domain ownership for `gradabroad.online` was successfully verified in Google Search Console using the existing domain-provider DNS record for the already authorised account. Keep that TXT record in place. Search Console provides search-query/click, indexing, HTTPS and Core Web Vitals reports without adding tracking scripts to the website.

After the deployment is live, submit `https://www.gradabroad.online/sitemap.xml` through the property's Sitemaps report and inspect the homepage/catalogue URLs. Submitting a sitemap and requesting indexing do not guarantee indexing, timing or rankings. Review actual data periodically in Search Console; this change does not create a scheduled monitoring job.

No paid SEO service, advertising, subscription, new hosting tier, database migration or new analytics tracker is used.
